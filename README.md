# Kaypoh

Weekly two-page Singapore newsletter. Produced every Thursday by a scheduled Claude routine and emailed to Calvin.

- `EDITORIAL.md` — audience, voice, curation rules, sources, verification. Read this first.
- `template/issue-template.html` — the fixed design. Copy it, replace content, never change the CSS.
- `issues/` — one HTML (and PDF when rendered) per issue, named `YYYY-MM-DD-issue-NNN`.
- `render.sh` — renders an issue HTML to A4 PDF with whatever browser is available.

Design decisions are settled. Issue 001 (10 Sep 2026) is the reference for tone and layout.
